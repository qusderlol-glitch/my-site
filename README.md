# GTA VI Troll Site

Пародийная страница «скачать GTA VI за $0.19 / 1 MB». Кнопка Download запускает
фейковую загрузку, на 66% вылезает горилла с «FOOLS!» и играет сюрприз-звук.

## Как опубликовать на GitHub Pages
1. Залей все файлы в репозиторий `my-site` (вкладка **Add file → Upload files**, перетащи сюда `index.html`, папки `assets/` и `downloads/`, нажми **Commit**).
2. Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / **/(root)** → Save.
3. Через 1–2 минуты сайт откроется по адресу: https://qusderlol-glitch.github.io/my-site/

Не связано с Rockstar Games. Это прикол.
